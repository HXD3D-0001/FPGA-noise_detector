# 实测与参考数据

在工程根目录运行 `python -B data/check.py` 可离线复算以下数据。各组试验分开记录，声压级为板端估算值。

| 试验 | 文件 | 数据与用途 |
|---|---|---|
| 十分钟连续采集 | `ten_minute_observations.csv` | 真实 ADC 左声道，208 份串口观测；每行列出相对首条读数的接收时间及十带数字电平（dBFS）。可核对界面滚动保留的 180 个点与最大接收间隔。 |
| 同一长测的 SD 结果 | `ten_minute_bands.csv`、`ten_minute_check.json` | 板端总时长 610.234 秒，有效 606.208 秒，覆盖 99.34%；六条标记均同步，存储路由丢弃一次。可逐带比较 SD 结果与导出值。历史重放沿用这次会话的观测。 |
| 独立窗口短测 | `display_check.json` | 单独核对实时与汇总两组十带读数、四个趋势点和导出。SD 中 100 Hz 为 −45.53 dBFS，窗口显示估算声压级 74.6 dB。 |
| 整场导出短测 | `full_session_observations.csv`、`full_session_short_run.json` | 另一次真实 ADC 串口采集，共 12 份观测和两条 SD 已确认标记。前一个文件取自整场导出的时间序列；后一个文件保留标记表中的对应读数及实板操作结果。 |
| 十段受控声源 | `speaker_steps.csv` | 从 250 Hz 至 31.5 Hz 依次播放，每段 10 秒，段间静音 5 秒。各段目标频带的稳态中位数减去播放前同带的背景中位数。 |

## 如何核对整场导出

短测的两份文件共用一个时间原点，即首条频谱在电脑上的接收时刻。时间以毫秒记录。CSV 的十个频带列为估算声压级（dB），JSON 中标记的十个读数依 `centers_hz` 排列。用同段时间序列中距离提交时刻最近的读数匹配每条标记；限前后 5 秒，等距取较早者。以读数时刻减去提交时刻，两条标记分别为 +299 ms 和 +1413 ms。脚本会重算这两个差值，并把标记表上的十个频带逐一对回时间序列。

暂停界面的频谱请求期间，后台已记录观测从 5 条增至 8 条。该计数取自窗口试验记录。正常停止并读回 SD 后，正式导出包含完整时序和标记表两份 CSV、一份可离线打开的 HTML，以及十份单频带 SVG，合计 13 项。提交样例仅保留复算所需的相对时间、频带数值与计数。

十分钟历史重放使用原有 208 份观测。整场导出功能本身的实板证据来自上述独立短测；时长和样本数应分别解读。绝对声压精度仍需逐带与参考仪器比对。
