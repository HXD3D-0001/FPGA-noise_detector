# 实测与参考数据

数据为 2026 年 11 月 1 日的台架验证。只保留指标、相对时间和数字读数；原始录音、标记文本、会话及设备标识均未纳入。固件与位流的字节身份在 `board/firmware.json`。

| 文件 | 试验及验证范围 |
|---|---|
| `ten_minute_observations.csv` | 1.5.0、真实 ADC 左声道。208 份实际取得的频谱，时间从第一份接收起计。数字电平单位为 dBFS。末次界面滚动窗口中保留的 180 项标记为 1；原始窗口核验逐点对比十带值。串口轮询不是硬件帧计数。 |
| `ten_minute_bands.csv` | 同次正常停采后的 SD 汇总。每带列出板端原始电平、板端换算读数及独立导出值，100 Hz 为 72.5 dB。 |
| `ten_minute_check.json` | 观察阶段 600.300 s；板端总长 610.234 s，有效 606.208 s，有效覆盖 99.34%。6 条标记均同步，存储路由丢弃 1 次、溢出 0 次。独立重开串口回读的完整记录与上位机接收的 SD 原文 SHA-256 相同。 |
| `speaker_steps.csv` | 从 250 Hz 至 31.5 Hz 依次播放十段测试音，每段 10 s、间隔静音 5 s。每段稳态中位数减去播放前同一频带的背景中位数。250、200、160 Hz 分别升高 21.32、9.66、14.87 dB，其余七段变化幅度小于 4 dB。 |
| `display_check.json` | 另开的 1.5.1 实板短会话。检查了两组十带读数、4 个趋势点及导出；SD 中 100 Hz 为 −45.53 dBFS，窗口显示 74.6 dB。 |

十段实验参考比较文件的原始 SHA-256 为 `ef2ffe9a70f0ae58d086dbc69710475e812f2bf998644919fe170b6ba45805c5`。两个界面版本的核验收据哈希分别列在对应 JSON 文件中。历史验收覆盖的范围为频带响应、系统运行和读写一致性；绝对声压精度须依据独立仪器比对。

在工程根目录执行 `python data/check.py`，即可复算覆盖率、分频实验差值，检查实卡各带读数与导出一致，并按时间序列核对收到的观测次数及滚动窗口大小。该检查只读取已归档数据。
