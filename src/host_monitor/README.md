# AX7021 监测上位机

展示时将电脑网口与开发板 ETH0 直连，使用同一子网的地址。上位机也支持 USB 串口（115200、8N1）。固件、接线和启动见[板卡说明](../../board/README.md)。

在此目录执行 `python server.py`，打开程序输出的本地 URL。串口模式需要 Python 3.12 或更新版本及 pyserial 3.5。桌面窗口入口是 `window/main.cjs`，构建步骤见[构建说明](../../build/README.md)。

## 整场记录与导出

从上位机点击“开始采集”，保持本地服务运行。服务按会话、捕获段和配置持续保存收到的频谱，时间采用电脑接收时间；十个频带各保留一列声压级（dB）。断线期间无返回的时段会在曲线上断开。实时窗口的滚动点数不限制整场导出。

点击“停止并保存”，等板卡 SD 汇总读回，再点击“一键导出完整记录”。ZIP 包括全部观测行的时间序列 CSV、住户标记声压 CSV、十份单频带 SVG 和可离线打开的 HTML 汇总报告。“查看整场图表与标记表”可在软件内预览。原有 JSON、CSV、HTML 按钮仍用于仅导出十个频带的声压级。

住户标记保存提交时间和板端记录。匹配同一捕获段内距离提交时刻最近的读数，最大允许偏差 5 秒；表中列出读数时间与有符号时间差。没有可靠时间或邻近读数时留空。导出表使用 UTC，曲线横轴为相对秒数。标记备注随整场 ZIP 导出。

## 离线复查整场记录与导出

在工程根目录执行以下命令。第一条使用临时数据库和测试数据，检查记录持久化、标记最近点匹配、导出 CSV、HTML 和 SVG。第二条用随包实测数据复查同一批观测与标记。

```sh
python -B -m unittest discover -s src/host_monitor -p "test_session_*.py"
python -B data/check.py
```

整场导出短测的[脱敏数据](../../data/full_session_short_run.json)来自单独的真实 ADC 会话。十分钟长测的历史文件可用于回放，回放时长不计入这场短测。
