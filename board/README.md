# AX7021 板上运行

适用板卡为 ALINX AX7021、XC7Z020-2CLG484。使用 MAX4466、PCM1808 模块与可启动的 FAT SD 卡。竞赛本地工程包随附用于复现的 `capture.bit`；公开仓库提供 [PL 源码](../src/rtl/) 和 [ARM 固件源码](../src/ps/) 供重建。完整启动镜像包含 FSBL、PL 和 ARM 程序。配套工具和既有板测镜像记录见本目录。

## 准备启动镜像

使用本工程 `build/` 入口从源码构建，或从已持有的 BandEstimate 原产品包恢复经过板测的同一份镜像。后者需要 Python 3.11 或更高版本。先在工程目录以外新建一个空部署目录，然后执行下列命令，将尖括号内的参数替换成实际路径。

```text
python board/prepare_boot.py "<原产品包 ZIP>" "<外部空部署目录>"
```

脚本检查来源归档和镜像是否匹配，输出 `BOOT.BIN` 并读回。若目标目录已含同名文件，脚本会停止。采用自建镜像时，单独记录构建条件，并完成启动和实板回读验证。

## 接线与开机

断电后识别板载 J16 第一脚。MAX4466 的输出接 PCM1808 的 LIN，麦克风用 3.3 V，ADC 模块接 5 V 和 3.3 V，所有模块共地。MD1、MD0 各经 10 kΩ 上拉，FMT 经 10 kΩ 下拉。FPGA 的 J16-3 向 ADC SCK 输出约 12.288 MHz，ADC 的 BCK、LRC 和 OUT 分别接 J16-33、J16-4 和 J16-5。正式输入为 48 kHz、24 位 I²S 左声道。

备份现有启动文件，手动把已核验的 `BOOT.BIN` 放在可启动 SD 卡 FAT 分区根目录。按所用板卡修订版手册选择 SD 启动，插卡上电。展示时电脑有线网口通过一根网线连接开发板单独的 ETH0。板卡无 DHCP 时使用链路本地地址 `169.254.70.21/16`，可将电脑有线网口设为 `169.254.70.10/16`。

## 运行和验收

1. 打开独立上位机，选择以太网、输入板卡地址并连接。点击开始采集；看到 ADC 左声道处于运行状态后，选择 250 Hz 频带。板端启停、存储和频带分析均在开发板执行。
2. 维持同一增益，在固定位置播放测试音，等待谱窗更新。提交一条测试标记，停播后点击停止并保存。等板卡确认文件关闭，再读取 SD 报告。以现场读数和有效时长为准。
3. 可在采集期间从另一终端执行 `python board/read_board.py 169.254.70.21` 获取 HTTP 状态和当前频谱。脚本只发送 GET 并输出至控制台。网络访问需实际链路通畅。
4. 复现十分钟长测时，选择实际 USB 串口（115200、8N1），连续采集至少 600 s，期间完成六轮频带切换、同端口重连和标记。主动停止后，核对四个存储文件的接收和同步计数、六条标记及十带导出。独立窗口短测另行核对显示字段；整场导出短测另行核对全程曲线、标记匹配与文件内容。三组试验结果见[实测数据说明](../data/README.md)。

公开分发前应复核本方授权与第三方工具生成物的许可。编译生成物与许可、工具安装、私有调试记录需分别审核。
